# Handoff native binary

This is a platform-specific binary package used by
[`@walid-baharwal/handoff`](https://www.npmjs.com/package/@walid-baharwal/handoff).
Install the main package instead:

```bash
npm install -g @walid-baharwal/handoff
```

The application is implemented in Go. This package exists only so npm installs
the correct native Handoff binary for the current operating system.
